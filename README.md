# FFOnto Book

A guide to FFOnto, the Forest Fire Ontology: development lifecycle, data sources, FFOnto-Bot, querying with SPARQL,
and citation. It is a static site (plain HTML, CSS and a little JavaScript) that GitHub Pages serves directly.

```
src/
  nav.json              chapters and sections (the navSections structure)
  content/<chapter>.html  chapter text
  home.html             title page
  site.json             title, version, links (used as {{placeholders}} in the pages)
  template.html         page layout
  build.py              generates the pages (Python 3, no packages needed)
assets/                 book.css, book.js, favicon, search-index.json (generated)
index.html, docs/…, 404.html   generated by build.py – do not edit by hand
.github/workflows/pages.yml    rebuilds and publishes on every push
```

## Edit

1. Change text in `src/content/*.html`, chapters and sections in `src/nav.json`, and links in `src/site.json`.
   - Write links inside the book from the site root, for example `href="/docs/using-ffonto#sparql-examples"`. The build makes them relative, so they work at any GitHub Pages address.
   - Every `#anchor` in `nav.json` needs a matching `<h2 id="anchor">` in the chapter, or the build stops with an error.
   - Put code in `<pre><code class="language-sparql">…</code></pre>`. Code is highlighted at build time; supported languages are sparql, turtle, json, python, shell, bibtex and text.
2. Build and preview:
   ```bash
   python3 src/build.py
   cd .. && python3 -m http.server 8000      # then open http://localhost:8000/ffonto-book/
   ```

## Publish on GitHub Pages

1. Create a repository named `ffonto-book` on GitHub. Any other name works; then set `base_path` in
   `src/site.json` to `/<name>/`.
2. Push this folder:
   ```bash
   cd ffonto-book
   git init -b main
   git add -A
   git commit -m "FFOnto Book"
   git remote add origin https://github.com/kosala0514/ffonto-book.git
   git push -u origin main
   ```
3. On GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
   The workflow runs and the book appears at `https://kosala0514.github.io/ffonto-book/`.
   Every later push rebuilds and republishes it.

Prefer no Actions? Choose **Source: Deploy from a branch**, branch `main`, folder `/ (root)`. Then run
`python3 src/build.py` before each commit, because the generated pages are committed too.

## Before publishing

Check the links in `src/site.json`. `bot_repo_url` and `book_repo_url` point to repositories that may not exist
yet. Create them, or change the links to your real repositories.
